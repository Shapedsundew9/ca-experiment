# Phase 1 Archive — LIF Substrate Exploration

This directory contains the complete, archived record of Phase 1: the Leaky Integrate-and-Fire (LIF) spiking substrate exploration campaign (CAMPAIGN-2026-MVA-SUBSTRATE).

## Contents

- `experiments/` — The 11 experiment packages (exp_2026_001a through exp_2026_011a)
- `tests/` — Integration test files for all experiments
- `bin/` — Experiment runner and calibration binaries
- `research/` — Campaign state, hypotheses, protocols, run manifests, and diagnostics

## Status

**Archived.** This work is a completed exploratory campaign. The experiments, findings, and methodology are valid scientific results. They are preserved here for reference but are not the foundation for future work.

See `research/CAMPAIGN-PHASE-1.md` for the full campaign history.
See `docs/misc/understanding-the-011a-confound.md` for the educational walkthrough of the key finding.
